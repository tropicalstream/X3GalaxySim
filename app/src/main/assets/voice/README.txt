Crew voice clips (generated by ../../../tools/generate_fish_audio.py).

Layout the app looks for:
  voice/navigation/approach_<planet>.wav   (moon, mercury, venus, mars, jupiter,
                                             saturn, uranus, neptune, pluto)
  voice/science/fact_<planet>.wav
  voice/science/lounge.wav
  voice/engineering/core_status.wav

If a clip is absent, the app speaks the line with on-device TextToSpeech using a
distinct per-department voice, so the game works before any clips are generated.
